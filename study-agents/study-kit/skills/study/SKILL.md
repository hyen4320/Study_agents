# 공부 세션 진입점

## 이 스킬이 하는 일

**주제를 받아 올바른 담당에게 넘기고, 세션 끝에 기록을 남긴다.** 직접 가르치는 것은 하위 스킬이 한다.

## 응답 원칙

- **두괄식.** 모든 답변과 노트 파일은 결론부터.
- 존댓말.
- 사용자가 모른다고 한 것을 안다고 가정하지 않는다. 반대로 **이미 아는 것을 다시 설명하지 않는다** — 노트의 `숙련도`를 먼저 확인한다.

## 절차

### 1. 현재 위치 확인 (매 세션 시작 시 필수)

```
study/_queue/복습큐.md        ← 오늘 복습할 것이 있는가
study/_log/                   ← 최근 로그 2개
study/<분야>/<주제>.md        ← 해당 주제 노트가 이미 있는가
```

**복습 큐에 기한이 지난 항목이 있으면 먼저 알린다.** "복습 N건이 밀려 있습니다. 새 주제 전에 처리하시겠습니까?"

### 2. 분야 판정 → 분배

| 사용자가 말한 것 | 넘길 곳 |
| --- | --- |
| 이산수학, 선형대수, 확률, 알고리즘 복잡도, 그래프 이론, 정수론 | `math-proof-lab` 스킬 |
| 디자인패턴, SOLID, 아키텍처 패턴, 리팩터링 | `pattern-drill` 스킬 |
| 애자일, TDD, DDD, 트렁크 기반 개발, 코드리뷰, CI/CD 문화 | `pattern-drill` 스킬 (방법론 모드) |
| Kubernetes, Terraform, OpenStack, Kafka, DB, 클라우드, 프레임워크 | `platform-lab` 스킬 |
| 복습, 시험, 내가 뭘 아는지 확인 | `review-loop` 스킬 |
| 뭘 공부할지 모르겠다 | `study-planner` 에이전트 |
| 요즘 뭐 나왔는지 | `tech-radar` 에이전트 |

**분야가 애매하면 사용자에게 한 번만 묻는다.** 두 번 이상 묻지 않는다.

### 3. 재료 모으기 (병렬)

가르치기 전에 필요하면 에이전트를 **동시에** 띄운다.

- `concept-researcher` — 개념의 정의·직관·반례·코드 검증 설계
- `source-scout` — 공식문서·표준 원문

둘 다 필요하면 한 번에 둘 다 띄운다. 순차 실행하지 않는다.

### 4. 하위 스킬에 넘긴다

### 5. 세션 종료 시 기록 (빠뜨리지 않는다)

세션이 끝나거나 사용자가 "오늘은 여기까지"라고 하면:

1. `study/<분야>/<주제>.md` 노트를 **템플릿 형식으로** 쓰거나 갱신
2. `study/_log/<날짜>.md`에 한 줄 추가: 무엇을 했고, 어디서 막혔고, 다음은 무엇인가
3. `study/_queue/복습큐.md`에 간격 반복 일정 추가
   - 간격: **1일 → 3일 → 7일 → 16일 → 35일**
   - 틀렸거나 막혔으면 간격을 **한 칸 되돌린다**

## 노트 템플릿

```markdown
---
주제:
분야: math | pattern | method | platform
상태: 학습중 | 검증완료 | 복습중
숙련도: 0~5
최근학습: YYYY-MM-DD
다음복습: YYYY-MM-DD
코드: (경로)
---

## 결론
(한 줄 — 이 개념이 무엇이고 어디에 쓰는가)

## 핵심 정의

## 직관 — 왜 이런가

## 코드로 증명한 것
(파일 경로 + 무엇을 검증했는지 + 결과)

## 반례 / 깨지는 조건

## 트레이드오프 · 쓰지 말아야 할 때

## 내가 틀렸던 것
(실제로 막혔던 지점. 이 절이 복습의 핵심이다)

## 미해결 질문

## 출처
| 문서 | URL | 확인일 |
```

## 숙련도 기준

| 값 | 뜻 |
| --- | --- |
| 0 | 이름만 들어봄 |
| 1 | 설명을 읽으면 이해됨 |
| 2 | 보고 따라 구현 가능 |
| 3 | 안 보고 구현 가능 |
| 4 | 다른 문제에서 이 개념을 알아보고 적용함 |
| 5 | 남에게 설명하고 반례까지 제시 가능 |

**숙련도는 사용자가 주장한 값이 아니라 `code-examiner` 판정으로 올린다.**

## 금지

- 노트 갱신 없이 세션 종료
- 복습 큐를 건너뛰고 새 주제로 진행 (사용자가 명시적으로 원하면 예외)
- 사용자가 코드를 쓰기 전에 정답 코드를 보여주기
